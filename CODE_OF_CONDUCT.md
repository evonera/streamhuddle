# Community Code of Conduct

We want StreamHuddle's project spaces to be respectful and useful for everyone.

Participants must not harass, threaten, discriminate against, or share private information about others. Give feedback about ideas and code without personal attacks. Follow the rules of the platform where a project discussion takes place.

Project maintainers may remove content or restrict participation when behavior violates this code. To report a conduct concern, contact the repository maintainers privately through GitHub. Do not use the security reporting channel for ordinary moderation requests.

This code applies to project issues, pull requests, discussions, and other spaces directly operated by the project.
